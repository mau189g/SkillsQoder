# 代码审查清单

审查是**只读**动作：先评估再确认修复。输出分层问题表，致命问题必带"位置 + 为什么错 + 怎么改（可直接替换代码）"。

## 1. 严重级别定义

- **致命**：崩溃、死循环、数据错乱、内存泄漏、安全漏洞、越权、注入、响应式丢失、未清理副作用。
- **次要**：可维护性/性能/类型问题，不改持续偿还利息。
- **可选**：风格与偏好。

## 2. 通用审查清单（全栈）

**致命**
- [ ] 是否存在 panic/未捕获异常/空指针/越界路径
- [ ] 是否存在注入（SQL/命令/NoSQL）、XSS、CSRF、越权（信任前端传入 ID/角色）
- [ ] 是否泄露密钥/Token/隐私（代码/前端/日志）
- [ ] 并发：数据竞争、goroutine 泄漏、未取消 context、共享可变状态
- [ ] 事务/回滚：写操作无回滚预案、部分失败数据不一致

**次要**
- [ ] 错误处理：吞错（`err==nil` 忽略）、未 `%w` 包装、字符串比较分支
- [ ] 可读性：命名、幽灵代码、假注释、万能 try-catch、过度抽象
- [ ] 类型：滥用 `any`、缺类型定义、断言掩盖问题
- [ ] 性能：N+1、未预分配、重复渲染、缺失缓存、热点未优化
- [ ] 重复：复制粘贴逻辑、可提取公共函数

**可选**
- [ ] 风格是否符合前端/Go 规范（见 `frontend-spec.md` / `go-backend.md`）
- [ ] 注释必要性、日志级别、命名一致性

## 3. 前端专项（Vue / React）

- [ ] 响应式丢失（解构 props、ref 塞 reactive）
- [ ] 副作用未清理（监听器/定时器/onMounted 外 watch）
- [ ] SSR 安全（window/document 在 onMounted/SSR 分支）
- [ ] v-if + v-for 同元素、缺 key、深层 reactive 大对象
- [ ] XSS：`v-html` 未可信内容、用户输入未消毒

## 4. 后端专项（Go）

- [ ] error 处理/包装、`errors.Is/As`、sentinel 位置
- [ ] context 首参、defer cancel、goroutine 有界
- [ ] 接口在消费方、无包级可变状态、依赖注入
- [ ] 热路径：slice 预分配、strings.Builder、sync.Pool
- [ ] `gofmt/goimports/go vet` 干净、errcheck 无未检错误
